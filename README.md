## 🚀 How to Publish to GitHub Pages (100% Free - 2 Minutes)

Follow these simple steps to make your portfolio live worldwide at `https://<your-github-username>.github.io`:

### Step 1: Create a GitHub Repository
1. Log into your account at [GitHub.com](https://github.com).
2. Click the **"+"** icon in the top right corner $\rightarrow$ Select **New repository**.
3. Name your repository: `<your-github-username>.github.io`  
   *(Example: if your GitHub username is `akash-ude`, name it `akash-ude.github.io`)*.
4. Set the visibility to **Public**.
5. Do NOT check "Initialize with README" (we already have our files ready).
6. Click **Create repository**.

---

### Step 2: Push Portfolio Files to GitHub
Open PowerShell in this portfolio directory (`c:\Users\akash_ude\Documents\agy-projects\adk-workspace-2\akash-portfolio`) and run:

```bash
git init
git add .
git commit -m "Initial commit - Akash Professional Portfolio"
git branch -M main
git remote add origin https://github.com/<your-github-username>/<your-github-username>.github.io.git
git push -u origin main
```

---

### Step 3: Enable GitHub Pages (Instant Hosting!)
1. In your GitHub repository, click on **Settings** (top tab).
2. On the left sidebar, click **Pages**.
3. Under **Build and deployment** $\rightarrow$ **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Wait 60 seconds! Your portfolio will be live at:  
   👉 **`https://<your-github-username>.github.io`**
